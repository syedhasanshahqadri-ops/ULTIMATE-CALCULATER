# 🎓 Markly — Smart Marks Calculator

**Markly** is a modern, interactive, and responsive marks calculator that helps students calculate their total marks, overall percentage, and average marks in real time. With an intuitive interface, interactive sliders, smooth animations, and dark/light themes, tracking academic performance has never been easier.

## ✨ Features

- 👤 **Personalized Dashboard** — Enter your name and choose the number of subjects.
- 📚 **Custom Subjects** — Add subject names and set maximum marks individually.
- 🎚️ **Interactive Sliders** — Adjust obtained marks from zero to the maximum marks for each subject.
- ⚡ **Real-Time Calculations** — Instantly update marks, percentages, and averages as sliders move.
- 📊 **Visual Progress Tracking** — View overall progress with animated progress rings and subject-wise progress bars.
- 🌙 **Dark & Light Mode** — Switch between dark and light themes.
- 💾 **Save Results** — Save your marks locally in your browser and restore them later on the same device and browser.
- 📥 **Download Results** — Export your academic results as a CSV file.
- 🔄 **Reset Marks** — Reset all obtained marks to zero.
- ✏️ **Edit Subjects** — Update subject names and maximum marks.
- 📱 **Fully Responsive** — Designed for mobile phones, tablets, laptops, and desktop screens.
- 🎨 **Modern UI** — Enjoy a clean interface with gradient accents, smooth transitions, and subtle animations.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Responsive layouts, themes, animations, and styling.
- **JavaScript** — Interactive sliders, calculations, local storage, and CSV export.
- **Browser Local Storage** — Saves results on the user's device.

## 🧮 Calculation Formulas

**Overall Percentage**

```text
Overall Percentage = (Total Obtained Marks / Total Maximum Marks) × 100
```

**Average Marks**

```text
Average Marks = Total Obtained Marks / Number of Subjects
```

**Subject Percentage**

```text
Subject Percentage = (Obtained Marks / Maximum Marks) × 100
```

### Example

Suppose a student has 7 subjects, each with a maximum of 100 marks.

| Metric | Result |
|---|---:|
| Number of Subjects | 7 |
| Total Maximum Marks | 700 |
| Total Obtained Marks | 560 |
| Overall Percentage | 80% |
| Average Marks | 80 |

## 💾 Data & Privacy

- Results are stored locally in your browser when you use the Save feature.
- No backend server or external database is required.
- Saved results are not automatically synchronized between devices or browsers.
- Clearing your browser's site data may remove saved results.
- Downloaded CSV files can be opened with spreadsheet applications such as Microsoft Excel or Google Sheets.
